# DRIVE / LOG · PJT2–5 구현 및 검증 결과

검증일: 2026-10-15. 기존 서울 20반 장문수·최현준 프로젝트를 기준으로 확장했습니다.

## 결과

사용자가 지정한 프로젝트와 명세서·강의자료 PDF 8개를 분석하고, PJT2–5의 기본·심화 요구사항 44개를 코드에 반영했습니다. 기존 정적 인포테인먼트 화면을 Vue 3 화면 8개로 옮기고 Firebase 인증, 실시간 로그, 차트, 관리자 기능, AI 대화 경로를 연결했습니다.

코드 구현과 외부 서비스 검증을 구분했습니다. Google 실제 로그인과 서버 프로필 저장을 확인했고, 마이크 문장 인식·스피커 출력은 사용자 정상 확인을 받았습니다. Kakao/OpenWeather의 기존 키를 복구해 지도·검색·길안내·현재 날씨·예보의 실응답까지 검증했습니다. GMS의 실제 생성 응답은 API 키가 없어 검증하지 못했습니다.

## 주요 변경

- 로그: 행별 원문 저장, Firestore 생성 트리거 정제, 실시간 갱신, KST 날짜·등급·운전자·키워드 복합 필터, 정렬·페이지·상세 탐색, 중복 업로드 방지와 실패 재시도.
- 분석: Chart.js 속도·엔진 온도·가속도·연비 차트, 평균·최대·최근 값, 임계치 조정, 과속·과열·급가감속·충격 감지. 결측값과 음수 가속도 보존.
- 계정: 기본 익명 계정, 회원가입·자동 로그인, 이메일 중복 확인, 선택 프로필 인증, Google OAuth, 닉네임·비밀번호·배경·프로필 사진 변경.
- 관리자: 일반 계정에 숨긴 회원 관리 탭, 전체 회원 조회, 서버에서 권한을 확인한 관리자 승격, 최초 관리자 지정 명령.
- 대화: 즉시 말풍선·로딩·시간·스크롤·고정 입력창, 회원 권한 확인, 본인 로그 분석 문맥, Firestore 이력, 요청 ID 기반 재시도, 한국어 STT/TTS.
- 기존 화면: 홈·내비게이션·날씨·음악 UI 유지 및 Vue 이전. 키 미설정 시 연결 안내를 표시합니다.
- 데이터 보호: 로그인 계정과 로그의 운전자 ID 분리, 타 계정 로그·대화 차단, 역할과 대화의 서버 전용 쓰기, 이미지 업로드 제한.

에뮬레이터 Google 검증은 합성 credential을 사용하므로 실제 Google 동의 창 검증을 대신하지 않습니다. AI 성공 응답 테스트는 주입한 테스트 어댑터를 사용하며 제품에서 가짜 AI 응답을 만들지 않습니다. 권한 거부 테스트의 PERMISSION_DENIED 로그는 예상된 결과입니다.

추가 검증에서 빈 좌표와 공백을 0으로 변환해 유효 좌표로 받는 오류를 재현했습니다. 값이 비어 있으면 400 INVALID_COORDINATES로 거부하도록 수정했고, 실제 숫자 0은 허용하는 회귀 테스트를 추가했습니다.

Vite는 Firebase SDK가 포함된 초기 청크 크기 경고를 표시합니다. 차량 배경의 정적 URL 경고는 빌드 후 자산 복사 및 브라우저 표시로 확인했습니다. 둘 다 빌드 실패는 아닙니다.

## 실제 Firebase

### 관리자 회원 관리

![관리자 전용 탭과 회원 목록](screenshots/pjt5/admin.jpg)

화면의 회원과 주행 기록은 로컬 검증용 합성 데이터입니다.

기존 `drive-log-pjt2-260911-7a90f` 프로젝트를 Chrome에서 복구했습니다. 이메일/비밀번호·익명·Google 제공업체, Storage, Firestore 규칙·인덱스, 서버 함수 7개를 연결했습니다. 실제 클라우드 검증에 생성한 임시 계정과 해당 계정의 데이터는 정리했습니다. 사용자의 기존 데이터를 삭제하거나 덮어쓰지 않았습니다.

배포 지역은 asia-northeast3, 함수 런타임은 Node.js 22입니다. 기본 Storage는 US-EAST1입니다. 배포 후 Artifact Registry 정리 정책 미설정 경고가 있었으며, 실제 배포 함수 호출은 통과했습니다. Hosting은 공개 배포하지 않았습니다.

## 추가 검증과 남은 외부 조건

Google OAuth: 사용자 로그인 완료 후 Chrome에서 새로고침해도 회원 세션이 유지되고, 회원 설정과 챗봇에 접근하며 관리자 탭은 숨겨짐을 확인했습니다. Firebase 서버에서도 google.com 인증, 활성 상태, user 권한, 프로필·공개 디렉터리 저장을 확인했습니다.

![실제 Google 로그인 후 회원 설정](screenshots/pjt5/google-login-verified.jpg)

음성: 2026-10-15 사용자가 실제 소리와 문장 인식 모두 정상이라고 확인했습니다. 프로젝트 음성 모듈을 불러오는 임시 검사 화면을 제공했습니다. 브라우저 이벤트 기록은 수집되지 않아 실제 장치 결과는 사용자 실기 확인으로 구분합니다. GMS 실생성 응답→음성 출력 전체 연계는 아래 키 복원 후 확인해야 합니다.

| 항목 | 구현·검증 상태 | 필요한 조건 |
| --- | --- | --- |
| 실제 GMS 응답 | 서버 연동·문맥·오류·재시도 구현, 어댑터 검증 통과 | GMS API 키 및 허용 모델. 현재 사용자께서 재발급이 어렵다고 확인하셨습니다. |

지도·날씨 연결은 완료했습니다. Kakao의 기존 무료 쿼터 앱 Infortainment System과 OpenWeather의 Car Information 키를 사용합니다. 로컬 .env와 Firebase Secret Manager를 설정하고 webApi를 재배포했으며, 클라우드 실응답까지 검증했습니다. 기존 키를 재사용했으며 유료 구독이나 새 앱을 만들지 않았습니다.

## 실행 및 인수인계

현재 소스 위치: `C:\Users\SSAFY\Desktop\jms\pjt5\DRIVE-LOG`.

```powershell
npm ci
npm --prefix functions ci
npm run start:local
# 별도 터미널에서 합성 체험 계정 및 로그 생성
npm run seed:local
```

Java 21 이상이 필요합니다. 로컬 앱은 http://localhost:4173 이며 체험 계정은 `demo-member@example.test`, `demo-admin@example.test`, 초기 비밀번호는 둘 다 `Drive-log-demo-123!`입니다. 기본 SSAFY 계정에는 비밀번호가 없습니다. 실제 Firebase는 비공개 설정을 복구한 현재 PC에서 `npm start`로 실행합니다. 상세 설정은 README를 참고하세요.

제출 ZIP에는 Vue·Functions·스크립트·테스트·규칙·설정 예시·검증 문서를 포함합니다. 실제 키·CLI 토큰·서비스 계정·에뮬레이터 데이터·원본 제공 문서·node_modules는 제외합니다. ZIP 내부의 파일 목록과 SHA-256을 생성하고 압축 해제 결과의 바이트를 대조합니다.

44개 기능별 코드 위치와 검증 근거는 [요구사항 표](../docs/requirements.md)에 정리했습니다. Git 커밋·푸시·GitLab 제출은 실행하지 않았습니다.
